WHAT IT DOES

  • Exports the finished audio plus a timings.json — one timestamp per line, so video cuts land exactly on the words
  • Generates line by line: fix one sentence, re-generate only that line
  • Runs on your own Windows PC — your scripts stay on your machine
  • Free — no credits, no per-character pricing

GOOD TO KNOW

Edge voices need the internet. They are generated by Microsoft's online voices, so Voice Studio has to be connected while you use them.

Kokoro voices work offline. The model ships with the app and runs entirely on your PC — slower on old machines, but no connection needed.

Built for one job: voiceovers for faceless videos. It is not a podcast studio or an audio editor.

The story

Every Blob video starts as a text script. The narration has to be generated line by line — one file, exact timings — because the picture is cut against the voice, not the other way around. Off-the-shelf TTS tools either read a whole script in one take (fix one word, redo everything) or hand back audio with no timing map. Voice Studio is the small tool built for that one workflow: paste the script, pick a voice, get the voiceover and the timings file this channel's editor cuts to. It is open source — the code lives on GitHub.
